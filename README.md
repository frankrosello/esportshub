# EsportsHub

**Current Version: 0.6.0 — Backend Development**

EsportsHub is a web-based esports management platform designed to help collegiate esports organizations manage teams, players, schedules, and competitive activities in one centralized location. The application provides role-based functionality for administrators, game managers, team captains, and players, allowing organizations to coordinate their esports programs more efficiently.

The platform includes team and roster management, event scheduling, player availability tracking, attendance reporting, and match history. Captains can submit scrimmage results and VOD reviews, while players can view team information, manage their availability, and access upcoming events. EsportsHub also supports private player concern submissions, accessible only to authorized management personnel.

EsportsHub is currently in active development, with **Overwatch** serving as the initial supported game. The application is built using HTML, CSS, and JavaScript, with a backend powered by Cloudflare Workers and a Turso database. The goal is to provide a free, accessible, and scalable management solution for collegiate esports organizations.

## Development Status

**Version 0.6.0** introduces the initial backend infrastructure, including database schemas, authentication, role-based permissions, and API endpoints. The existing frontend remains in development, and full backend integration is not yet complete.

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Cloudflare Workers
- **Database:** Turso (SQLite)
- **Hosting:** GitHub Pages

## Project Status

This project is under active development and is not yet ready for production use.
