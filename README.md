# EsportsHub

**A web-based management platform designed for collegiate esports organizations.**

EsportsHub was developed to simplify the organization and management of competitive esports teams. Originally created for Florida Polytechnic University Esports, the platform provides a centralized workspace for administrators, game managers, team captains, and players.

The application brings together team management, scheduling, player availability, and communication tools in a single interface, reducing the need to coordinate activities across multiple platforms.

## Features

**Team Management**
- Manage multiple competitive games and teams within one organization.
- Organize team rosters and assign players to their respective teams.
- Manage administrators, game managers, captains, and players through role-based permissions.

**Scheduling & Availability**
- Schedule scrimmages, practices, matches, and other team events.
- Submit weekly availability through an interactive scheduling grid.
- Coordinate team activities and view upcoming events.

**Reports & Communication**
- Create shared scrimmage reports, match summaries, and VOD reviews.
- Maintain team-specific notes and feedback.
- Submit private player concerns for review by authorized management.

**Authentication & Access**
- Secure user authentication powered by Clerk.
- Invitation-based account registration.
- Role-specific access to management tools and team information.

**User Interface**
- Responsive design supporting desktop and mobile devices.
- Automatic light and dark modes based on device settings.
- Mobile navigation and touch-friendly controls.
- A clean, purple-themed interface inspired by Florida Polytechnic University.

## User Roles

| Role | Description |
|---|---|
| **Administrator** | Oversees the organization, games, teams, and staff permissions. |
| **Game Manager** | Manages teams and operations for assigned games. |
| **Captain** | Coordinates team activities, scheduling, and reports. |
| **Player** | Accesses team information, submits availability, and views schedules. |

## Technologies

EsportsHub is built using:

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Cloudflare Workers
- **Database:** Turso (libSQL)
- **Authentication:** Clerk
- **Hosting:** GitHub Pages

## Project Status

EsportsHub is actively being developed, with ongoing improvements to team management, scheduling, user experience, and organizational tools.
