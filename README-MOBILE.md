# EsportsHub mobile-responsive update

Replace `index.html`, `css/style.css`, and `js/portal.js` with these files. Keep your existing backend unchanged.

Updates: slide-out mobile sidebar with working dimmed backdrop, Escape to close, accessible menu state, responsive cards/forms/login, scrollable half-hour availability timetable, and automatic device color scheme.

On a phone, tap the menu button at top left. Swipe *horizontally inside the availability grid* to see other days; tap a half-hour square to toggle it. On a desktop, the sidebar remains visible.

After uploading to GitHub Pages, refresh or clear cached files. This package uses your current Clerk test publishable key; switch to a Clerk production instance and custom domain before inviting real users. Test browser sign-in and API permissions before real data.
