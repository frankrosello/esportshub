OVERWATCH SCRIM TOOLS

Workshop Log Analysis

Import a ScrimTime Workshop Inspector log to review map and player statistics inside EsportsHub.

Import a Log

In Overwatch, enable the Workshop Inspector log file and host your custom game with ScrimTime code Z0ASA. Import the exported text file from Documents/Overwatch/Workshop. This is EsportsHub’s local analyzer, not the Parsertime service or its skill-rating system.

Logs are processed locally in your browser. Only a report summary is shared if you choose to publish it.
