# Overwatch Map Images

Map screenshots and catalog retrieved from the public OverFast API (https://overfast-api.tekrop.fr/maps) on October 17, 2026. Screenshots depict Blizzard Entertainment’s Overwatch maps. Images were resized for the map-pool interface. Map availability is descriptive, not a statement of the current NECC season pool. Club staff choose the pool manually.

Additional screenshots for Neon Junction and Grímsvötn were obtained from Blizzard’s official announcements:
